# Промпты

Каждый файл здесь — часть запроса к модели. Правятся через PR, версия промпта
записывается в черновик (`drafts.prompt_version`).

| Файл | Для чего | Появится |
|---|---|---|
| `style/styleguide.md` | правила канала: длина, тон, эмодзи, запреты, структура | заполняет редакция (шаг 6) |
| `style/examples/*.md` | эталонные посты целиком, по одному на файл | заполняет редакция (шаг 6) |
| `style/relevance-examples.md` | заголовки «взяли / не взяли» с одной фразой почему | заполняет редакция (шаг 8) |
| `rank.md` | инструкция для отсева кандидатов | шаг 11 |
| `draft.md` | инструкция для черновика | шаг 12 |
| `edit.md` | инструкция для правки по замечанию редактора | шаг 12 |
| `manual.md` | инструкция для поста из сообщения редактора | шаг 15 |
