# Взяли / не взяли

Примеры для ранжирования. Заголовок, решение, одна фраза почему. Ориентир: пост нужен, если студент медиакома после него делает что-то иначе (проверяет, пробует, спорит) или понимает, откуда взялась привычная ему вещь.

| Заголовок | Решение | Почему |
|---|---|---|
| Google объединила AI Overviews и AI Mode: поиск превращается в диалог | взяли | Меняет то, как аудитория находит контент, а значит и то, как его делать. |
| OpenAI и Hugging Face раскрыли инцидент: модель вышла за пределы тестовой среды | взяли | Наглядный кейс про поведение агентов, есть два первоисточника с разных сторон. |
| Исследование OpenAI и MIT: как пользователи эмоционально привязываются к ChatGPT | взяли | Тема близка читателю, есть данные, можно повесить опрос. |
| Найден исходный код ELIZA, первого чат-бота 1966 года | взяли | История, которая объясняет сегодняшний эффект «понимающего собеседника». |
| Три признака дипфейка, которые видно без специальных инструментов | взяли | Практика для фактчека, ложится в карточки. |
| Пять чат-ботов не смогли договориться, какая модель лучшая | взяли | Собственный мини-эксперимент редакции, показывает границы доверия к ИИ. |
| Adobe добавила генерацию видео по тексту в Premiere | взяли | Инструмент, которым студенты пользуются на курсах, изменение рабочего процесса. |
| Суд в ЕС вынес решение по делу об обучении модели на текстах СМИ | взяли | Прямое следствие для будущих авторов и редакций, нужен разбор с выводом. |
| Nvidia представила новый чип для дата-центров | не взяли | Железо без последствий для работы с медиа, читатель ничего не сделает иначе. |
| Стартап привлёк 200 миллионов долларов на ИИ для логистики | не взяли | Инвестновость из чужой индустрии, вывода для медийщика нет. |
| Модель X обошла модель Y на бенчмарке на 1,3 пункта | не взяли | Гонка цифр без изменения практики, к тому же завтра лидер сменится. |
| Илон Маск пообещал выпустить ИИ, который умнее всех людей, к концу года | не взяли | Обещание без продукта и источника, пересказ заявления. |
| Пресс-релиз: банк внедрил чат-бота для клиентов | не взяли | Пресс-релиз без вывода, канал не пишет про корпоративные внедрения. |
| Утечка: следующая версия ChatGPT получит новую функцию | не взяли | Слух без первоисточника, нельзя называть версию, которой нет в источнике. |
