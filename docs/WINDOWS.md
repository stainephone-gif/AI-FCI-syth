# Установка на Windows

Понадобится около 15 минут и интернет. Все команды вводятся в PowerShell:
нажать Win, набрать «PowerShell», Enter. Каждую команду вставлять целиком
и нажимать Enter. Сокращение `(.venv)` в начале строки означает, что
окружение проекта включено.

## 1. Python

1. Открыть python.org/downloads, скачать Python 3.12 для Windows.
2. Запустить установщик. **Обязательно отметить галочку «Add python.exe to
   PATH»** внизу первого экрана, затем «Install Now».
3. Проверить в PowerShell:
   ```powershell
   py --version
   ```
   Должно быть `Python 3.12.x`. Если PowerShell пишет, что `py` не найден,
   закрыть его и открыть заново: путь подхватывается только в новом окне.

## 2. Git

1. Открыть git-scm.com/download/win, скачать «64-bit Git for Windows Setup».
2. Установить, во всех окнах оставить значения по умолчанию.
3. Закрыть PowerShell и открыть заново. Проверить:
   ```powershell
   git --version
   ```

Без Git можно обойтись: на странице проекта в GitHub выбрать ветку
`claude/fervent-maxwell-uqv3j7`, кнопка Code → Download ZIP, распаковать в
`C:\Users\ВАШЕ_ИМЯ\AI-FCI-syth`. Тогда шаг 3.1 пропускается. Но обновлять
код придётся заново скачивая архив, с Git это одна команда.

## 3. Проект

1. Скачать проект в домашнюю папку:
   ```powershell
   cd ~
   git clone -b claude/fervent-maxwell-uqv3j7 https://github.com/stainephone-gif/AI-FCI-syth.git
   cd AI-FCI-syth
   ```
2. Создать окружение и включить его:
   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```
   Если PowerShell отвечает, что выполнение сценариев запрещено, один раз
   выполнить:
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```
   ответить `Y`, и повторить `.venv\Scripts\Activate.ps1`. В начале строки
   появится `(.venv)`.
3. Установить зависимости и браузер для карточек:
   ```powershell
   pip install -e ".[dev]"
   playwright install chromium
   ```
   Первая команда идёт две-три минуты, вторая скачивает около 150 МБ.
4. Проверить, что всё собралось:
   ```powershell
   pytest -q
   ```
   Ожидается строка вида `50 passed`. Тесты не ходят в интернет и не
   тратят токены.

## 4. Настройки

1. Создать файл настроек из образца и открыть его в Блокноте:
   ```powershell
   copy .env.example .env
   notepad .env
   ```
   Открывать именно так, из PowerShell: если создавать файл через Блокнот
   вручную, он сохранится как `.env.txt` и не будет прочитан.
2. Для консольного режима достаточно заполнить одну строку:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
   Сохранить (Ctrl+S) и закрыть Блокнот. Остальные строки пока не трогать.

## 5. Консольный режим, без Telegram

В PowerShell с включённым окружением, из папки проекта:

```powershell
python -m app.cli collect
```
Сбор источников и оценка кандидатов. Через минуту-две в окне появится
отчёт и десять лучших заголовков с оценками.

```powershell
python -m app.cli digest
```
Черновики для лучших кандидатов, текст печатается в окно, карточки
сохраняются в папку `data\cards`.

```powershell
python -m app.cli post "в четверг семинар с ИТМО про агентов, начало в 18:00"
```
Пост из сообщения редактора с блоком «Проверьте даты».

```powershell
python -m app.cli card "Заголовок карточки" "Подзаголовок"
```
Карточка в `data\cards\test.png`, открыть двойным щелчком в Проводнике.

Промпты правятся в папке `prompts` любым редактором, повторный `digest`
подхватывает их сразу. Чтобы переписать черновики после правки промпта,
удалить файл `data\syth.db` и снова выполнить `collect`, потом `digest`.

## 6. Полный режим с Telegram

Нужны бот, чат редакции и канал-дублёр из раздела 1 файла
`docs/TEST-WEEK.md`. В `.env` заполнить `BOT_TOKEN`, затем запустить:

```powershell
python -m app.main
```

Пока `EDITOR_IDS` пуст, бот отвечает только на `/whoami`. Написать
`/whoami` в чате редакции, получить id, вписать в `.env` строки
`EDITOR_IDS`, `EDITOR_CHAT_ID`, `CHANNEL_ID`, нажать Ctrl+C в PowerShell и
запустить снова. Бот работает, пока открыто окно PowerShell.

## 7. В следующий раз

Каждый новый сеанс начинается с трёх команд:

```powershell
cd ~\AI-FCI-syth
.venv\Scripts\Activate.ps1
git pull
```

Третья подтягивает правки разработчика. После неё иногда нужен
`pip install -e ".[dev]"`, если менялись зависимости.

## Если что-то не так

- **`py` или `git` не найдены**: закрыть PowerShell и открыть заново; если
  не помогло, переустановить Python с галочкой «Add to PATH».
- **`ModuleNotFoundError: No module named 'app'`**: PowerShell открыт не в
  папке проекта или не включено окружение, нет `(.venv)` в начале строки.
- **`ANTHROPIC_API_KEY пуст`**: файл называется `.env.txt` или ключ не
  сохранён. Проверить: `Get-Content .env`.
- **Ошибка сети при `collect`**: с компьютера не открываются сайты
  источников или API моделей, проверить в браузере.
- **Антивирус ругается на Chromium** при `playwright install`: разрешить,
  это браузер для рендера карточек.
