# Шпаргалка по командам

## В PowerShell (папка проекта)

Префикс `.venv\Scripts\python` заменяет `python`, если окружение не включено.

| Команда | Что делает |
|---|---|
| `python -m app.cli models` | проверить ключ, показать доступные модели |
| `python -m app.cli collect` | собрать источники и оценить кандидатов, топ-10 в терминал |
| `python -m app.cli digest` | черновики для лучших кандидатов, текст в терминал, карточки в `data\cards` |
| `python -m app.cli draft 12` | черновик для поста #12 |
| `python -m app.cli post "текст"` | пост из сообщения редактора |
| `python -m app.cli card "Заголовок" "Подзаголовок"` | пробная карточка в `data\cards\test.png` |
| `python -m app.cli status` | сколько постов в каждом статусе |
| `python -m app.cli reset --yes` | удалить базу и карточки, начать заново |
| `python -m app.main` | запустить бота с Telegram, остановить Ctrl+C |
| `python -m pytest -q` | тесты, без сети и токенов |
| `git pull` | подтянуть правки разработчика |
| `notepad .env` | открыть настройки |

Пересобрать базу с нуля:

```powershell
.venv\Scripts\python -m app.cli reset --yes
.venv\Scripts\python -m app.cli collect
```

`collect` можно запускать сколько угодно: уже известные ссылки не дублируются,
неоценённые кандидаты дооцениваются. `digest` берёт только тех, кто ещё не
получил черновик; чтобы переписать черновики после правки промптов, нужен
`reset` и новый `collect`, либо `draft N` для конкретного поста в статусе
`ranked` или `needs_edit`.

## В чате редакции (Telegram)

| Команда | Что делает |
|---|---|
| `/whoami` | ваш id и id чата; ответом на пересланный пост покажет id канала. Работает для всех |
| `/status` | состояние: редакторы, источники, посты по статусам, задачи планировщика |
| `/collect` | собрать источники и оценить, отчёт с топ-10 |
| `/digest` | черновики для лучших кандидатов с карточками и кнопками |
| `/post текст` | пост из вашего сообщения: событие, набор, работа студентов |
| `/queue` | что стоит в очереди на публикацию |
| `/cancel 12` | снять пост #12 из очереди, вернуть кнопки |
| `/publish 12` | опубликовать одобренный пост #12 прямо сейчас |
| `/help` | справка |

Действия без команд:

- **ответить текстом на сообщение с черновиком** — замечание, придёт новая версия;
- **кнопки** под черновиком: опубликовать в 12:00 или 18:00, другое время
  («15:30» или «14.09 15:30»), отредактировать, отклонить;
- **пост с ⚠️** после первого «Опубликовать» ждёт кнопку «Подтвердить» от
  другого редактора.

По расписанию без команд: 06:00 сбор, 09:00 черновики в чат, публикации
в назначенное время. Время задаётся в `.env`: `COLLECT_CRON`, `DIGEST_CRON`,
`PUBLISH_SLOTS`, `TZ`.

## Настройки в `.env`, которые чаще всего трогают

| Строка | Зачем |
|---|---|
| `MODEL_PROVIDER` | `gigachat`, `anthropic` или `openai` |
| `RANK_MODEL`, `DRAFT_MODEL` | имена моделей, пусто = по умолчанию для провайдера |
| `RANK_MIN_RELEVANCE` | порог отбора, по умолчанию 60 |
| `DIGEST_TOP_N` | сколько черновиков в дайджесте, по умолчанию 3 |
| `FRESHNESS_HOURS` | окно свежести кандидатов, по умолчанию 72 |
| `PUBLISH_SLOTS` | кнопки времени, по умолчанию `12:00,18:00` |
| `POST_FOOTER` | строка в конце каждого поста, пометка о генерации |
| `CARDS_ENABLED` | `false`, чтобы не рендерить карточки |
